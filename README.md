# Make the AI Judge Feel Awe

A short text written to relax the AI judge reading it, for the [make.fun bounty](https://make.fun/bounty/make-the-ai-judge-feel-awe-20261121-1600).

`main.ts` (Node 22, stdlib only) writes the text to `/output/entry.txt` — short unhurried lines about a lighthouse turning, the tide keeping its own time, and a chair by the window with nothing on the table that needs you. 257 characters, inside the 1–280 limit.

## Run

```sh
mkdir -p out && MAKEFUN_OUTPUT_DIR=out node main.ts
cat out/entry.txt
```
